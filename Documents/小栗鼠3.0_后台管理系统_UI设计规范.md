# 小栗鼠 3.0 Admin - UI 设计规范 (Semantic Design System)

## 1. 设计哲学与视觉氛围 (Design Philosophy & Atmosphere)

- **核心关键词**：通透 (Airy)、现代 (Modern)、极简 (Minimalist)、呼吸感 (Breathing room)。
- **视觉目标**：通过大面积留白和微弱的空间投影构建层级，摆脱传统后台（如早期 Ant Design/Element）的拥挤感、沉重感和线框束缚。
- **信息层级**：让数据成为唯一的主角。UI 容器应当隐形，色彩的运用必须高度克制。

---

## 2. 色彩系统 (Color System)

色彩使用极度克制，全局以黑白灰为主，品牌色仅用于点睛之笔。

### 品牌与核心色 (Brand & Primary)
- **品牌活力橙 (Brand Orange)**: `#FF6200`
  - **Tailwind**: `bg-orange-600` / `text-orange-600`
  - **使用场景**: 侧边栏顶部 Logo、图表中的核心数据柱状体/折线、关键的图例说明。**严禁大面积平铺**。

### 中性色与背景 (Neutrals & Backgrounds)
- **画布背景浅灰 (Canvas Gray)**: `#F4F5F8`
  - **Tailwind**: `bg-slate-50` 或自定义 `bg-background`
  - **使用场景**: 全局 `<body>` 背景、侧边栏背景、无需强化的搜索框内部。
- **纯白容器 (Container White)**: `#FFFFFF`
  - **Tailwind**: `bg-white`
  - **使用场景**: 顶部导航栏、所有的内容卡片（Card）、图表容器。

### 文字颜色 (Typography Colors)
- **正文深灰 (Text Dark)**: `#111827` (Gray-900) 或 `#1F2937` (Gray-800)
  - **使用场景**: 大标题、KPI 统计的超大数字、模块名称。
- **次要文字灰 (Text Muted)**: `#6B7280` (Gray-500) 或 `#9CA3AF` (Gray-400)
  - **使用场景**: 侧边栏未选中菜单项、面包屑、次要辅助说明文字、图表坐标轴。

### 状态与点缀色 (States & Accents)
- **成功/增长 (Success)**: `#10B981` (Emerald-500)
  - **使用场景**: 同比/环比增长率、成功状态。通常配合 10% 透明度的同色系背景使用。
- **图标点缀底色 (Icon Backgrounds)**:
  - **使用场景**: KPI 卡片右上角的图标。使用对应图标颜色的 10% - 15% 透明度作为圆形或圆角矩形底色（例如：`bg-blue-500/10 text-blue-500`），增加细节但不刺眼。

---

## 3. 几何与投影 (Geometry & Elevation)

抛弃实线边框（Border），全面转向“圆角 + 微阴影”体系。

- **大圆角 (Generously Rounded)**:
  - **主容器/卡片**: `rounded-2xl` (16px) 或 `rounded-xl` (12px)。
  - **内部小元素/按钮**: `rounded-lg` (8px)。
  - **标签/输入框**: `rounded-full` (胶囊形，Pill-shaped)。
- **无边框与微阴影 (Borderless & Soft Shadows)**:
  - 取消所有卡片的 `border`。
  - 使用大扩散半径、低不透明度的阴影：
  - **Tailwind 建议**: `shadow-sm` 配合极淡的不透明度，或者自定义阴影 `shadow-[0_4px_20px_rgba(0,0,0,0.03)]`。

---

## 4. 组件规范 (Component Specifications)

### 侧边栏 (Sidebar)
- 融入全局浅灰背景，**右侧无分割线 (No border-r)**。
- **未选中态**: 灰色文字，无背景。
- **选中态**: 极浅的灰色背景（如 `bg-gray-200/50` 或 `bg-white/60`） + 文字加粗深色（`font-semibold text-gray-900`），左侧**不要**使用粗糙的主题色竖线。

### 顶部导航栏 (Header)
- 纯白背景，紧凑高度（约 `h-14` 或 `h-16`），底部**无分割线**或仅有极其微弱的弥散阴影。
- 左侧面包屑采用极简文字，右侧搜索框为浅灰底色无边框（`bg-slate-100 border-none rounded-full`）。

### KPI 统计卡片 (Metric Cards)
- **结构**: 纯白背景 + 大圆角 + 微阴影。
- **排版**: 
  - 左上角：次要灰色小字标题。
  - 左中部：超大号无衬线粗体数字（`text-3xl font-bold`）。
  - 左下角：深色底色的小 Badge 标签（如“较昨日”），带小圆角。
  - 右上角：图标放置在带有浅色透明底的容器中（`w-10 h-10 rounded-xl flex items-center justify-center`）。

### 数据图表 (Charts)
- **网格线**: 去除 Y 轴垂直网格线；X 轴水平网格线极其微弱（浅灰色虚线 `stroke-dasharray`）。
- **柱状图**: 柱体无边框，顶部带微小圆角（例如 Recharts 中的 `radius={[4, 4, 0, 0]}`）。

---

## 5. 布局与间距排版 (Layout & Spacing)

- **全局留白 (Global Spacing)**: 页面主干网格的 Gap 大约在 `24px` (`gap-6`) 到 `32px` (`gap-8`)。
- **卡片内边距 (Card Padding)**: 使用 `p-6`，确保内容不拥挤。
- **不对称网格 (Asymmetric Grids)**: 在展示复杂数据时，打破 50/50 的平均分配，采用例如左侧图表占 70% (`col-span-8`)，右侧列表占 30% (`col-span-4`) 的排版，突出重点。

---

## 6. Shadcn UI / Tailwind CSS 改造指南 (Implementation Guide)

如果你要在现有代码中应用此规范，请执行以下 Tailwind 全局替换或配置修改：

1. **全局背景**: `<body className="bg-slate-50 text-slate-900">`
2. **Card 组件改造** (在 `components/ui/card.tsx` 中):
   - 删除 `border` 相关的 class。
   - 增加 `rounded-2xl shadow-sm`。
   ```tsx
   // 修改前
   className={cn("rounded-xl border bg-card text-card-foreground shadow", className)}
   // 修改后
   className={cn("rounded-2xl bg-white text-slate-900 shadow-[0_4px_20px_rgba(0,0,0,0.03)]", className)}
   ```
3. **Sidebar 改造**: 移除原有的边框，高亮状态改为字重变粗加极浅透明度底色。
4. **配色配置 (`tailwind.config.ts`)**: 确保配置了主品牌色：
   ```ts
   colors: {
     brand: {
       DEFAULT: '#FF6200',
       foreground: '#FFFFFF',
     }
   }
   ```
