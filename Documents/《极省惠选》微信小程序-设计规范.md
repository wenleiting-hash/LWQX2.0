# 《极省惠选/老温铺子》微信小程序 MVP UI 设计规范 V1.0

---

## 一、设计原则

| 原则 | 说明 |
|------|------|
| **WeUI 原生优先** | 强制使用微信官方 WeUI 组件库，禁止引入第三方 UI 框架，保障秒开体验 |
| **零摩擦** | 最短操作路径 ≤3 步，无登录弹窗、无冗余页面 |
| **合规至上** | 全端 UI 彻底封杀"返现/返利/佣金"，统一使用"积分"表述 |
| **适老友好** | 支持大字号 + 暗黑模式，核心信息字号不低于 28rpx |

---

## 四、字体排版

### 4.1 字体栈

```
font-family: -apple-system, BlinkMacSystemFont, 
  "Helvetica Neue", "PingFang SC", "Microsoft YaHei", 
  sans-serif;
```

### 4.2 字阶系统

| 层级 | 字号 (rpx) | 字重 | 行高 | 用途 |
|------|------------|------|------|------|
| **D1 - 数据大字** | 64rpx | Bold (700) | 1.2 | 积分余额大数字 |
| **H1 - 大标题** | 40rpx | Semibold (600) | 1.3 | 页面标题 |
| **H2 - 小标题** | 34rpx | Medium (500) | 1.4 | 卡片标题、商品名 |
| **Body - 正文** | 28rpx | Regular (400) | 1.5 | 正文描述、列表项 |
| **Caption - 辅助** | 24rpx | Regular (400) | 1.4 | 时间戳、标签、说明文字 |
| **Mini - 极小** | 20rpx | Regular (400) | 1.3 | 角标、徽章 |

### 4.3 金额/积分专用

| 场景 | 格式 | 示例 |
|------|------|------|
| 券后价 | `¥` + 数字（Bold） | **¥29.9** |
| 原价 | 删除线 + 灰色 | ~~¥59.9~~ |
| 预估积分 | 主色 + `formatMoneyToPoints()` | <span style="color:#FF6B35">预估可得 12.5 积分</span> |

> [!CAUTION]
> 所有涉及佣金/返利的金额字段，**必须**经过 `formatMoneyToPoints()` 函数处理后才能渲染，严禁直接展示现金数值。

### 7.1 底部 TabBar（4 Tab）

| Tab | 标签 | 图标风格 |

- 卡片背景：`#FFFFFF`，圆角 16rpx，阴影 `0 2rpx 12rpx rgba(0,0,0,0.06)`

## 十一、合规红线清单

> [!CAUTION]
> 以下为**不可违反**的硬性规则，违反即封号。

| 编号 | 红线 | 执行标准 |
|------|------|----------|
| R1 | **禁用敏感词** | UI 全文禁止出现"返现、返利、佣金、提成、分成"，统一用"积分" |
| R2 | **禁止提现入口** | 不得出现绑定银行卡、提现按钮、现金转出的任何 UI 元素 |
| R3 | **禁止直连三方** | 前端不得直接请求聚合平台 API，必须经云函数中转 |
| R4 | **禁止物流页面** | 不做物流追踪，订单详情底部灰字提示"物流请前往官方平台查看" |
| R5 | **金额强制转换** | 所有佣金数值必须经 `formatMoneyToPoints()` 处理后展示 |

## 十二、适老化与无障碍

| 项目 | 规格 |
|------|------|
| 最小可点击区域 | 88 × 88 rpx |
| 文字最小字号 | 24rpx（极小场景），正文不低于 28rpx |
| 对比度 | 文字与背景对比度 ≥ 4.5:1 |
| 大字号模式 | 通过 `app.json` 配置 `"resizable": true` 响应系统字号 |
| 暗黑模式 | `"darkmode": true`，使用 `@media (prefers-color-scheme: dark)` 适配 |
