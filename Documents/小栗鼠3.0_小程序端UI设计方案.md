# 小栗鼠 3.0 UI设计与页面交互方案 (小程序端)

**文档状态**: 定稿
**更新日期**: 2026-04-29
**适用对象**: UI设计师、前端研发（小程序端）

---

## 第一部分：全局视觉与品牌规范 (Global UI Guidelines)

基于小栗鼠“亲和、高信任、强转化”的品牌定位及元宝橙松鼠 Logo，结合最新视觉模板规范，制定以下基础视觉准则：

### 1. 设计基准与布局 (Layout & Size)

- **基准设备**：iPhone X (1倍图)，分辨率 `375 × 812 pt`
- **全局边距 (Margin)**：左右安全边距 `10pt`
- **高度规范**：
  - 状态栏 (Status Bar)：`44pt`
  - 导航栏 (Navigation Bar)：`44pt`
  - 底部标签栏 (TabBar)：`49pt`
  - 底部安全区 (Home Indicator)：`34pt`

### 2. 色彩系统 (Color System)

- **品牌主色 (Brand Primary)**：`#FF6200` (活力松鼠橙)。从 Logo 提取的核心主色。用于强诱导按钮（立即购买/一键转链）、底部 TabBar 选中状态、金额数字高亮、选中态标识。
  - _渐变拓展 (可选)_：`linear-gradient(to right, #FF8A2B, #FF6200)` 作为大按钮背景。
- **品牌辅助色 (Brand Secondary)**：
  - `#FFF0E5` (松鼠浅橙)：用于当前页面的标签底色、选中状态背景块。
  - `#2A2E5B` (深邃蓝)：用于次级操作、会员卡片背景，与亮橙色形成冷暖互补。
- **功能状态色**：
  - `#F33300` (红色)：错误提示、异常状态、极低价标签。
  - `#269F5A` (绿色)：操作成功、已完成状态。
- **中性色底板 (Surface & Background)**：
  - 小程序背景：`#F8F8F8` / `#F4F5F8` (极浅灰)，配合白底商品卡片（`#FFFFFF`）形成空间投影层级。
  - 分割线/未选中色块：`#F2F2F2`。
- **文本层级 (Typography Colors)**：
  - 主标题/正文核心信息：`#000000` / `#111827`。
  - 副标题/列表描述：`#515151` / `#646464`。
  - 注释/时间/提示语：`#A6A6A6`。

### 3. 字体规范 (Typography)

- **首选字体**：中文使用 `PingFang SC` (iOS)，备选 `Alibaba-PuHuiTi` / `Source Han Sans CN`；数字强调用 `DIN Alternate`。
- **字重与字号阶梯**：
  - 8pt~12pt (Regular)：标签、提示、副标题说明文字。
  - 14pt (Regular/Medium)：**基准正文**、卡片小标题、表单文字。
  - 16pt~18pt (Medium/Bold)：大按钮文字、卡片主标题、导航栏标题。
  - 24pt~40pt (Heavy)：特殊强调数字（如：提现金额、到手价）、弹窗成功提示大字。

### 4. 图标与组件规范 (Icons & Components)

- **质感与形状**：全面应用 `32rpx` (约 `16px`) 大圆角，隐去硬边框实线。
- **弥散阴影**：卡片使用极浅的弥散阴影 `box-shadow: 0 8rpx 32rpx rgba(0,0,0,0.03)` 区分层级，体现亲和萌宠与现代通透感。
- **毛玻璃效果**：针对悬浮条或弹出层，适度使用 `backdrop-filter: blur(16px)`。

### 5. 交互与动效要求 (Motion & Interaction)

- **按键反馈**：所有 CTA 按钮必须增加 `hover-class` (如 `btn-hover`) 的缩放反馈 (`transform: scale(0.98)` / `opacity: 0.9`)。
- **情感化反馈**：静默提取剪贴板进行转链时，使用微动效（<400ms），并在转链成功时配合手机微震动（Haptic Feedback）。
- **兜底插画**：缺省页需搭配带有小栗鼠的趣味 SVG 插画安抚情绪。

## 第二部分：核心主页面设计要点 (Main Tabs)

根据功能总表，严格按照 TabBar 划分为 4~5 个核心模块。

### 1. 首页 (Home) - 聚合查券入口
- **入口级探测**：当 `onShow` 截获含电商链接时，弹出极具抢眼度的半屏 Modal，主色调 `#FF6200` 按钮呈现“立刻查询”。
- **视觉焦点**：首屏减少细碎文字，用大图与醒目的价格标签驱动。

### 2. 发现 (Discover) - 双端大牌流
- **滑动 Tab**：顶部 Tab 支持滑动容器，分设淘宝系、京东系及多元专区。
- **Card UI 视觉**：增加双生态角标识别（淘宝/京东Logo及主色调），并动态算出“预估到手价”。

### 3. 热榜 (Rankings) - 跟风爆款
- **Top Card UI**：商品卡片增加 Top 1 金冠角标及“火热值”温度条。
- **双引擎混排**：混合请求淘宝与京东数据，让跨平台好货面对面。保留常规的单列瀑布流信息展现结构。

### 4. 晒单/广场 (Community) - 氛围营销
- **进场即时感**：进入 Tab 时，若 10 分钟内有新单，置顶弹出“最新播报提示条” (`刚刚某某下单了 xxx 节省了 xx 元`)。
- **盲盒式展示**：采用极简 FOMO 氛围，随机脱敏昵称滚动播报，提供一键“抄作业 / 跟买领券”大按钮。设计偏向社交动态风格。

### 5. 我的 (Mine) - 留存与私域
- **真实信息授权**：使用微信 OpenData 或最新登录流程动态加载真实昵称与头像，取代占位符。
- **极简合规**：彻底移除多余的复杂业务（如分销追踪），清理头部空间，突出“专业、精简”的个人中心。
- **私域导流优先级最高**：企微客服/联系我们区域需包装得像 VIP 邀请函，主色调按钮引导加群。

## 第三部分：二级页面设计规范 (Secondary Pages)

所有二级页面延续主页面的高斯模糊、大圆角与无边框风格，打造极致沉浸式体验。

### 1. 我的足迹 (My Footprints)
- **浏览结构**：以时间轴或清晰的单列图文流展示用户近期浏览的商品。
- **手势交互**：列表必须支持 `scroll-view` 的左滑删除交互 (Swipe-to-delete)，按钮颜色为警告色 `#F33300`，圆角与卡片内外呼应。
- **空状态**：若无足迹，展示可爱的松鼠空插画，并提供“去逛逛”按钮导流至首页。

### 2. 常见问题 (FAQ) & 使用教程 (Tutorial)
- **阅读体验优化**：深色标题配浅灰色正文 (`#646464`)，字号采用 `14pt`，行高设定为 `1.6`，保证充足的呼吸感。
- **布局模式**：采用折叠面板 (Accordion) 结构或清晰的富文本卡片分隔，避免长篇大论带来的视觉疲劳。
- **动态获取**：内容需由后端 API (`cf-get-config`) 动态渲染，支持后台实时修改发布。

### 3. 邀请好友 (Invite Friends)
- **海报卡片 (Poster Card)**：页面主体是一张精美的“VIP 邀请函”卡片（白底/浅橙底色，大圆角 `32rpx`，附带阴影），中心展示二维码或小程序码。
- **分享交互**：底部悬浮固定在安全区上方的 `#FF6200` 渐变色大按钮，调用微信原生 `button open-type="share"`，点击带有弹性动效反馈。

### 4. 联系我们 (Contact Us)
- **轻量级弹窗体验**：为了不打断用户的操作心流，不再作为完全独立的全屏页，而是通过微信原生 `page-container` 或自定义半屏组件 (Bottom Sheet) 呈现。
- **遮罩层**：弹出时底层页面应用黑色带透明度的遮罩层。
- **核心模块**：内部采用列表式排布，包含“联系客服”、“意见反馈”等入口，辅以微信官方开放能力接口。
