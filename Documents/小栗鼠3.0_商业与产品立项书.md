## 一、 核心商业与产品定调

### 1.1 产品愿景

小栗鼠是一款面向精算型消费人群的**纯导购工具型微信小程序**。以"剪贴板一键查隐藏券"为核心体验切口，帮助用户在淘宝/京东等主流电商平台购物时，零门槛获取全网最大面额隐藏优惠券，实现"不花冤枉钱"的极致省钱体验。

### 1.2 商业模式

采用**纯 CPS 导购分润模式**，通过折淘客等聚合 API 对接淘宝联盟、京东联盟的官方返佣通道。

**三条铁律红线**：

1. ❌ 绝不自建用户钱包与提现体系（规避资金池合规风险）。
2. ❌ 绝不引入多级分销代理（规避传销认定）。
3. ✅ 所有佣金全部归口至平台方自有的官方联盟账号，按官方结算周期到账。

### 1.3 目标用户画像

| 用户群体              | 典型场景                                  | 核心诉求                           |
| :-------------------- | :---------------------------------------- | :--------------------------------- |
| 🎓 在校大学生         | 生活费有限，买日用品/数码配件前习惯性比价 | 最低价、零门槛、不注册             |
| 👩‍👧 家庭主妇/宝妈      | 高频采购母婴/家居/食品，对价格极度敏感    | 大面额券、批量省钱、能分享给闺蜜群 |
| 📱 下沉市场薅羊毛达人 | 在各社交平台活跃，热衷搜集并传播优惠信息  | 快速出图发圈、有权威榜单可抄作业   |

### 1.4 核心业务飞轮

```
[流量获取] 晒单海报裂变 + 公域种草投放
      ↓
[体验引爆] 剪贴板秒劫持 → 直达大额隐藏券 → 实时弹幕/爆单榜激发跟风
      ↓
[留存沉淀] 极简大厂级 UI 建立品牌信任 → 养成"先来小栗鼠查价"的肌肉记忆
      ↓
[二次裂变] 用户自主生成海报分享 → 回到流量获取（闭环）
```

## 三、 产品设计规范 (Design Specs)

### 3.1 品牌视觉识别

| 设计项   | 规范值             | 用途说明                                        |
| :------- | :----------------- | :---------------------------------------------- |
| 品牌主色 | `#FF5500` 活力栗橙 | 仅用于核心 CTA 按钮（领券、生成海报）、价格高亮 |
| 全局底色 | `#F8F9FA` 冰灰白   | 大面积留白背景，杜绝电商大促的视觉污染          |
| 辅助色   | `#FF2D2D` 警示红   | 仅用于划线原价、限时倒计时等稀缺性暗示          |
| 文字主色 | `#1A1A1A` 墨黑     | 正文与标题                                      |
| 文字辅色 | `#999999` 银灰     | 次要信息、描述文字                              |

### 3.2 设计原则

1. **极简克制**：任何页面同时出现的主色不超过 3 种，坚决不使用红黄渐变的传销感配色。
2. **工具感优先**：首页（查券）追求"如 Google 搜索般的纯净感"，让用户 1 秒内知道怎么用。
3. **信息密度分层**：查券页极度留白 → 发现/榜单页中等密度 → 详情页高密度（算账对比）。

### 3.3 B 端设计风格

- 采用标准的数据看板（Dashboard）布局：左侧导航边栏 + 右侧主内容区。
- 高密度表格与表单为主，追求管理效率而非视觉花哨。

## 四、 技术架构与安全边界 (Architecture)

### 4.1 技术选型

| 层级       | 选型                          | 理由                                                   |
| :--------- | :---------------------------- | :----------------------------------------------------- |
| C 端框架   | 微信原生小程序 (WXML/WXSS/JS) | 放弃 Taro/uni-app 等编译框架，确保冷启动秒开的工具属性 |
| 服务端网关 | 微信云开发 (Cloud Functions)  | 零服务器成本、免运维、天然防 CORS、与小程序无缝鉴权    |
| 数据持久化 | 微信云数据库 (Cloud Database) | 存储全局配置（PID/AppKey/主题色）与用户足迹            |
| B 端管理台 | Next.js / Vue3 Web 应用       | 轻量现代框架，读写云数据库配置表                       |

### 4.2 安全红线（不可违反）

1. **🔴 前端零秘钥原则**：小程序代码包内严禁出现任何第三方 API 的 Key/Secret。
2. **🔴 云函数全代理原则**：所有折淘客/联盟 API 请求必须经由云函数在腾讯内网发起，前端仅调用 `wx.cloud.callFunction()`。
3. **🔴 PID 热切换原则**：高佣推广位 ID 存储在云数据库，支持 B 端后台 1 秒替换，前端下次请求自动生效，无需提交微信审核。

### 4.3 容灾降级设计

- **API 超时**：展示友好的骨架屏 + "优惠大部队正在路上" 文案，禁止裸露红字系统错误。
- **剪贴板权限被拒**：搜索框自动切换为脉冲高亮动效，暗示用户手动粘贴。
- **接口限流**：云函数层做请求排队与本地缓存，避免高峰期大量 429 错误穿透到前端。

### 4.4 微信平台合规底线（参照 weixin-rules.md · 不可违反）

> ⚠️ 以下条款一旦触发，微信官方将直接**限制功能能力或封号处理**，且无申诉窗口。所有产品设计与代码实现必须严格遵守。

| 微信条款编号 | 条款名称       | 我方涉及功能                     | 强制规避策略                                                                                                                                            |
| :----------: | :------------- | :------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------ |
|  **5.1.3**   | 诱导分享朋友圈 | 晒单页海报生成器、详情页一键制图 | 海报功能仅提供"保存到相册"，**严禁挂钩任何利益回报**（积分/红包/返现）。不得出现"分享到朋友圈领XX"类文案                                                |

|   **5.16**   | 过度营销行为   | 剪贴板探针弹窗                   | **每次小程序会话（session）仅允许触发一次剪贴板检测弹窗**。用户点击关闭后，本次会话内不再重复弹出。违反此条微信将直接封禁小程序的剪贴板读取能力         |

|   **6.3**    | 垃圾广告       | 商品详情页、搜索结果页           | **严禁使用绝对化用语**（"全网最低""绝无仅有""史上最便宜"），仅允许展示客观的原价/券后价数值对比。所有文案须符合《中华人民共和国广告法》                 |
|   **5.10**   | 互推行为       | 全局                             | 不得在小程序内设置跳转到其他小程序/APP 的集中入口或排行榜                                                                                               |

1. 所有涉及分享、弹窗、营销文案的 UI 组件，在提交微信审核前必须由 PM 逐一核查上述合规清单。

3. 实时弹幕组件的文案模板必须在 B 端后台可配置，便于审核期间快速调整措辞。

## 五、 运营策略与增长规划 (Operations)

### 5.1 冷启动打法（公域获客）

- **小红书**：以"信息差对比"公式批量产出种草笔记（如"原价189的纸巾，内部券后只要19！"），引导搜索小程序名"小栗鼠"。
- **抖音/快手**：制作 15 秒"查券实录"短视频，展示从复制链接到领券的完整流程，强调"不下载 APP、小程序直接用"。
- **微信群/朋友圈**：利用小程序内置的海报生成器，每日精选 3-5 款超高差价商品发圈。

### 5.2 私域沉淀运营

- 小程序"我的"页面设置客服活码，将高频用户导流至微信福利群。
- 福利群内每日定时用海报砸 3 轮单（早/中/晚），培养用户打开习惯。

### 5.3 核心监控指标（上线首日必须埋点）

| 指标            | 定义                           | 健康阈值 |
| :-------------- | :----------------------------- | :------- |
| 剪贴板触发率    | 成功读取剪贴板的用户占比       | ≥ 60%    |
| 搜索→详情转化率 | 搜索后点击查看商品详情的比例   | ≥ 40%    |
| 详情→口令复制率 | 查看详情后成功复制淘口令的比例 | ≥ 25%    |
| 海报生成率      | 使用海报生成功能的用户占比     | ≥ 5%     |
