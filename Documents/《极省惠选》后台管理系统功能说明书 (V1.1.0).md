# 《极省惠选/老温铺子》后台管理系统功能说明书 (V1.1.0)

## 一、 后端设计总纲

- **核心定位**：极简财务收银台与风控驾驶舱，而非全功能 ERP。
- **技术方案**：优先采用微信云开发自带的 CMS (内容管理系统)，将开发工作量压缩至 0.5 人天。
- **唯一准则**：只关注离钱最近的数据，坚决不做多级权限管理（只有超级管理员一个视角）。


----
## 二、 后台管理系统功能清单 (V1.0.0)


|**一级功能 (模块)**|**二级功能模块**|**核心功能描述 (系统能干什么)**|**CPO 算账与风控防线 (为什么这么做)**|
|:-:|:-:|:-:|:-:|
|**0. 登录与大盘***(核心指挥部)*|**0.1 极简单点登录**|超级管理员通过微信扫码或账号密码单点登录。|**【省钱防线】**：坚决不做多角色权限管理，MVP 阶段只保留创始人的上帝视角。|
||**0.2 LTV/CAC 财务看板**|核心数据展示：今日新增用户数、预估产生总佣金、已发放总积分。|**【算账本位】**：不看虚荣 PV/UV，只盯“拉新成本”与“佣金进账”的净水位差。|
|**1. 订单对账中心***(现金流命脉)*|**1.1 全局订单只读池**|列表展示云端定时任务从折淘客拉回的所有订单：订单号、金额、状态（待结算/已结算/已失效）。|**【自动化防线】**：此列表**仅限只读**，严禁手动修改订单状态，防范内部作恶与数据污染。|
||**1.2 异常坏账审计**|筛选出“官方已退款（已失效），但用户积分已被消耗”的坏账订单明细。|**【风控止损】**：用于动态调整“确认收货后次月发积分”的冷冻期策略。|
|**2. 用户资产管理***(合规隔离墙)*|**2.1 用户黑匣子档案**|仅展示用户的 OpenID、首次登录时间、当前可用积分余额、历史累计赚取积分。|**【隐私红线】**：不存储手机号、真实姓名和收货地址，彻底规避隐私合规风险。|
||**2.2 黑名单与资产冻结**|针对恶意刷单退款的用户，提供“一键冻结积分账户”的操作按钮。|**【资产护城河】**：这是极少数人工干预功能，死守老温铺子的实物兑换成本。|
||**2.3 🚫严禁手动发积分**|**(功能黑名单)** 绝对不允许在后台开发“手动给某人增加/扣除积分”的随意操作入口。|**【生死底线】**：积分发放必须 100% 自动挂钩官方结算，斩断人为造币造成资金断裂的可能。|
|**3. 自动化调度室***(零边际成本引擎)*|**3.1 TTL 神价缓存管理**|查看后台定时任务自动拉取的 50-100 款种草商品。支持一键手动清空当日缓存池。|**【甩手掌柜】**：不需要人工每天去选品上架。全靠 API 自动拉取，TTL 自动销毁。|
||**3.2 定时任务监控日志**|监控“拉取爆款任务”和“同步订单轮询任务”的执行日志（成功/失败）。|**【系统运维】**：确保全自动“印钞机”的齿轮没有卡壳停转。|
|**4. 系统全局配置***(核心开关)*|**4.1 API 密钥保险箱**|配置折淘客的 `AppKey` 以及淘宝/京东/拼多多的联盟 `PID`。|**【安全隔离】**：底层转链引擎密钥存放于环境变量中，严禁硬编码在前端。|
||**4.2 积分汇率配置**|配置现金佣金与系统积分的全局兑换比例（如默认 1:1，1元佣金=1积分）。|**【柔性套利】**：预留接口，未来可通过微调汇率进一步放大套利空间。|

## 三、 特别说明：老温铺子运营后台

- **业务脱钩**：本后台不包含任何电商商品上架、库存管理与快递发货功能。
- **微信小店集成**：所有实物兑换与发货操作，100% 寄生于官方免费的【微信小店】商家后台。
