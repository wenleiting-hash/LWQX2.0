# LWQX 3.0 页面模块与折淘客 API 对应清单

根据 `tmp/src/app/components` 目录下的全新 UI 设计结构，以及《折淘客接口调研表.md》，现将各页面的核心业务模块与需要调用的接口具体参数映射如下。

> **说明**：折淘客 API 体系中，一般端口 `10001`/`10002`/`10003` 代表淘宝生态，`20000` 端口代表京东生态。客户端展示时，通常需要在云函数层进行双端请求并按一定规则进行合并或独立召回。

## 1. 【首页】核心搜券模块 (Home.tsx)

**定位**：全局高转换漏斗，处理用户的主动文字/链接搜索请求与最终转链。

| UI 功能/交互触发 | 调用的折淘客 API | 关键参数 / 备注 |
| :--- | :--- | :--- |
| **搜券引擎** (输入文本或剪贴板链接) | **全网搜索商品API** <br/>淘宝：10003/`api_quanwang.ashx`<br/>京东：20000/`api_quanwang.ashx` | `q=[搜索词/链接解析词]` |
| **查询结果商品详情展示** | **全网商品详情API**<br/>淘宝：10002/`api_detail.ashx`<br/>京东：20000/`api_detail.ashx` | `tao_id=[商品ID]` |
| **点击“立即领券购买” (转链)** | **淘宝转链API**：20000/`open_gaoyong_...`<br/>**京东转链API**：20000/`open_jing_union...` | 必须传递用户真实的淘宝/京东长链或口令进行佣金结算链转换 |

---

## 2. 【发现】Feed流矩阵 (Discover.tsx)

**定位**：通过滑动 Tab 提供多维度的商品货架浏览，直接挂钩折淘客的高级类目筛选。

| UI Tab 分类 | 对应折淘客 API 及环境 | 接口关键过滤参数 |
| :--- | :--- | :--- |
| **淘宝特卖** | 淘宝：10001/`api_all.ashx` | 常规请求，可能附带 `tj=tmall` 或销量要求 |
| **品牌精选** | 淘宝：10001/`api_all.ashx` | `cid=0&pinpai=1` |
| **天猫超市** | 淘宝：10001/`api_all.ashx` | 配合特定 `keyword` 或特定店铺池 |
| **京东自营** | 京东：20000/`api_all.ashx` | `tj=tmall` （在20000下表征自营） |
| **京东好店** | 京东：20000/`api_all.ashx` | `tj=gold_seller` （在20000下表征京东好店） |
| **京东拼购** | 京东：20000/`api_all.ashx` | `jt=taoqianggou` （在20000下表征拼团） |
| **京东配送** | 京东：20000/`api_all.ashx` | `jt=juhuasuan` （在20000下表征211限时达等） |
| **9.9包邮专区** | 双端均调：`api_all.ashx` | `price=0.0-9.9` (聚合淘宝与京东数据) |
| **19.9包邮专区** | 双端均调：`api_all.ashx` | `price=0.0-19.9` |
| **大额神券** | 双端均调：`api_all.ashx` | `coupon_amount_start=100` 或 `tag=1`(超高券) |
| **品牌馆** | 双端均调：`api_all.ashx` | `pinpai=1` |

## 3. 【热榜】竞价与人气榜单 (Rankings.tsx)

**定位**：基于真实销量和平台热力值输出的全局货品排行榜。

| UI 榜单分类 | 对应折淘客 API 及环境 | 接口说明 / 备注 |
| :--- | :--- | :--- |
| **两小时爆款** | 双端均调：`api_xiaoshi.ashx` | 淘宝适用10001，京东适用20000。短时销量剧增的商品池。 |
| **实时人气** | 双端均调：`api_shishi.ashx` | 实时的流量点击与综合访问爆单榜。 |
| **全天销冠** | 淘宝：10001/`api_quantian.ashx` | 全天累加销量极高的霸榜好物。 |
| **月度王牌** | 京东：20000/`api_quantian.ashx` | 长跨度的优质货源（折淘客文档中20000下标注为了月榜）。 |
| **朋友圈热推** | 双端均调：`api_all.ashx` | \`tag=1\` (朋友圈火爆商品API)。 |

## 4. 【社区】盲盒兜底分发 (Community.tsx)

**定位**：制造购物 FOMO 情绪，并在缺乏回溯链接时，将流量导回首页中心化搜索引擎。

| UI 动作 | 对接的后台机制 / 调用的方案 | 备注 |
| :--- | :--- | :--- |
| **公屏信息滚动** | 定时拉取自有数据库的 `tk_orders` | 用于脱敏渲染谁赚了多少佣金，制造火爆假象。 |
| **点击：我也要买 (有短链接时)** | 调用 **转链API** (如 Home 逻辑) | 拿着历史订单保留的高佣金链接直转 |
| **点击：我也要买 (无短链接时)** | 调用 **全网搜索API** (`api_quanwang.ashx`) | 提取该播报订单的 `商品标题` 前 N 个字符，抛回给引擎模拟“文字搜券”的兜底推荐逻辑。 |

---

## 5. 【我的】私域流量回收层 (Profile.tsx)

**定位**：工具集与微信私域运营闭环支持层（完全剥离财务结算数据）。

| UI 入口 | 所需系统级支持 / API 支持 |
| :--- | :--- |
| **官方专属客服** | 无需折淘客API，对接微信小程序本身自带的 `<button open-type="contact">` 组件。 |
| **加入内部羊毛群** | 对接“企业微信”开放接口添加群引流。 |
| **我的找券足迹** | 调用自有云端 DB/本地缓存，展示用户搜过、查看过详情的商品 ID 列表数据。再根据 ID 回源请求折淘客 `api_detail.ashx`。 |
