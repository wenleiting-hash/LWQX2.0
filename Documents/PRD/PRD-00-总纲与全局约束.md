## 0.1 产品背景与问题陈述 (Problem Statement)

### 谁有这个问题？
精算型消费人群（在校大学生、家庭主妇/宝妈、下沉市场薅羊毛达人），在淘宝/京东等电商平台购物时，明知存在"隐藏优惠券"，但缺乏高效、可信、零门槛的工具来找到并使用这些优惠券。

### 有多痛？
- 用户通过搜索引擎找券：结果混乱，充斥虚假广告和过期链接，信任成本极高。
- 用户通过返利 APP 查券：需要下载安装、注册登录、绑定手机号，流程冗长，且多数 APP 界面充斥传销感。
- 用户通过微信群/朋友圈领券：信息碎片化，想买的商品未必有人发，且无法主动搜索。

### 不做会怎样？
用户继续以原价购买商品，平台方损失大量可通过 CPS 导购获取的联盟佣金收入。竞品（花生日记、好省等）持续侵蚀下沉市场用户心智。

## 0.2 全局成功指标 (Success Criteria)

以下指标适用于整个产品，各子模块的 PRD 中会定义更细粒度的指标。

### Phase 1.0 MVP 上线后 30 天内

| 指标 | 定义 | 目标值 |
| :--- | :--- | :---: |
| 首单转化 | 从"打开小程序"到"成功复制淘口令/京东链接"的端到端转化率 | ≥ 15% |
| 真实返佣 | 联盟后台产生至少 1 笔可确认的真实佣金记录 | ≥ 1 笔 |
| 日均 UV | 小程序每日独立访问用户数 | ≥ 50 |
| 海报生成率 | 使用过海报生成功能的用户占总 UV 比例 | ≥ 5% |
| 次日留存率 | 次日再次打开小程序的用户占比 | ≥ 20% |

### Phase 1.5 增长期（上线后 90 天）

| 指标 | 定义 | 目标值 |
| :--- | :--- | :---: |
| 日均 UV | 小程序每日独立访问用户数 | ≥ 500 |
| 月度预估佣金 | 联盟后台的月度预估收入 | ≥ ¥1,000 |
| 剪贴板触发率 | 成功读取剪贴板并弹出确认的用户占比 | ≥ 60% |

## 0.3 全局术语表 (Glossary)

| 术语 | 定义 |
| :--- | :--- |
| **淘口令** | 淘宝/天猫的加密分享口令（如 `￥aBcDeFg￥`），复制后打开淘宝 APP 可直达商品页 |
| **京东短链** | 京东商品的短网址（如 `https://u.jd.com/xxxxx`），点击后跳转京东 APP 或 H5 页面 |
| **PID** | 淘宝联盟推广位 ID，用于标识佣金归属。格式：`mm_xxx_xxx_xxx` |
| **AppKey** | 折淘客开放平台的开发者密钥，用于调用所有折淘客 API |
| **高佣转链** | 将普通淘宝/京东商品链接转换为带有联盟推广追踪参数的高佣金链接的过程 |
| **CPS** | Cost Per Sale，按销售额分成的佣金模式 |
| **折淘客 (ZTK)** | 第三方淘客聚合 API 服务商，提供查券、转链、榜单等一站式接口 |
| **云函数** | 微信云开发中的 Serverless 函数，运行在腾讯云内网，小程序通过 `wx.cloud.callFunction()` 调用 |
| **云数据库** | 微信云开发提供的 NoSQL 文档型数据库，用于存储全局配置与用户数据 |
| **FOMO** | Fear Of Missing Out，错失恐惧心理，营销中用于制造紧迫感的手段 |
| **CTA** | Call To Action，核心行动按钮（如"立即领券"、"生成海报"） |
| **Canvas 海报** | 使用微信小程序原生 Canvas API 在前端合成的商品推广图片，含商品图、价格、小程序码 |
| **活码** | 一个永久不变的二维码入口，其背后指向的实际微信号/群可在后台动态替换 |
| **Session** | 小程序的一次"会话"。用户打开小程序到主动关闭（或超过 30 分钟后台无操作）算一个 Session |
| **骨架屏** | 页面加载中的占位界面，以灰色色块模拟内容布局，避免白屏等待 |

## 0.4 全局技术约束与合规红线

### 0.4.1 技术选型约束

| 层级 | 选型 | 强制理由 |
| :--- | :--- | :--- |
| C 端框架 | 微信原生小程序 (WXML/WXSS/JS) | 放弃 Taro/uni-app 等编译框架，确保冷启动秒开 |
| 服务端网关 | 微信云开发 (Cloud Functions) | 零服务器成本、免运维、天然防 CORS、与小程序无缝鉴权 |
| 数据持久化 | 微信云数据库 (Cloud Database) | 存储全局配置（PID/AppKey/主题色）与用户足迹 |
| B 端管理台 | Vite + React 18 + TailwindCSS 4 + Radix UI | 轻量现代框架，复用现有 `admin` 项目基座，读写云数据库配置表 |

### 0.4.2 安全红线（所有 PRD 模块必须遵守）

| 编号 | 红线 | 违反后果 |
| :---: | :--- | :--- |
| SEC-01 | **前端零秘钥原则**：小程序代码包内严禁出现任何第三方 API 的 Key/Secret | AppKey 被逆向抓取，佣金被盗刷归零 |
| SEC-02 | **云函数全代理原则**：所有折淘客/联盟 API 请求必须经由云函数在腾讯内网发起 | 同上 |
| SEC-03 | **PID 热切换原则**：高佣 PID 存储在云数据库，B 端可 1 秒替换，无需提审 | 风控封号时业务不中断 |

### 0.4.3 微信平台合规底线（所有 PRD 模块必须遵守）

> ⚠️ 以下条款一旦触发，微信官方将直接限制功能能力或封号处理，且无申诉窗口。

| 微信条款 | 条款名称 | 我方涉及功能 | 强制规避策略 |
| :---: | :--- | :--- | :--- |
| **5.1.3** | 诱导分享朋友圈 | 海报生成器 | 仅提供"保存到相册"，**严禁挂钩任何利益回报** |
| **5.1.2** | 暗示用户分享 | 海报按钮 | 不得使用红点提醒、动态抖动等诱导性视觉效果 |
| **5.16** | 过度营销行为 | 剪贴板探针弹窗 | **每 Session 仅触发一次**，关闭后不再弹出 |
| **5.11** | 欺诈行为 | 实时订单弹幕 | **严禁"红包""免费领""中奖"**等虚假活动字样 |
| **6.3** | 垃圾广告 | 商品文案 | **严禁绝对化用语**（"全网最低""史上最便宜"） |
| **5.10** | 互推行为 | 全局 | 不得设置跳转到其他小程序/APP 的集中入口 |

### 0.4.4 容灾降级规范（所有 PRD 模块的 Edge Cases 必须引用）

| 场景 | 降级策略 | 禁止行为 |
| :--- | :--- | :--- |
| API 超时（>5 秒） | 展示骨架屏 + 友好文案"优惠大部队正在路上" | 禁止裸露红字系统错误或 Error Code |
| 剪贴板权限被拒 | 搜索框高亮脉冲动效，暗示用户手动粘贴 | 禁止强制弹窗要求授权 |
| 接口限流（429） | 云函数层排队 + 本地缓存上次结果兜底 | 禁止 429 错误穿透到前端 |
| 商品已下架/券已过期 | 详情页展示"该优惠已结束"并推荐同类商品 | 禁止显示空白页 |
| 网络断连 | Toast 提示"网络不给力，请检查后重试" | 禁止无反馈卡死 |

#### 晒单模块 (PRD-05) 数据源说明

> ⚠️ **晒单瀑布流的数据源不是"朋友圈火爆商品 API"**。晒单页展示的是用户通过小栗鼠实际下单购买的真实订单记录，数据源为：
> - **Phase 1.0**：运营者在 B 端后台手动精选并录入的"推荐晒单"商品（存储于云数据库 `featured_orders` 集合）
> - **Phase 1.5**：接入折淘客订单查询 API，自动拉取真实成交订单展示
