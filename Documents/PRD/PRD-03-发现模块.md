## 3.1 问题陈述 (Problem)

### 谁有这个问题？
没有明确购买目标、但有"逛一逛看看有什么便宜货"诉求的用户；以及已通过查券完成一笔交易、尚未离开小程序的"溢出流量"用户。

### 有多痛？
- 这类用户如果打开小程序只看到一个搜索框，会因为"没有买的欲望"而直接退出。
- 缺少一个"逛街式"的商品浏览入口，大量潜在成交机会被浪费。

### 不做会怎样？
小程序沦为纯工具，用户"用完即走"且不再回来，日活天花板极低。

## 3.2 成功指标 (Success Criteria)

| 指标 | 定义 | 目标值 |
| :--- | :--- | :---: |
| 发现页人均浏览商品数 | 用户在发现页滑动浏览的商品卡片数量 | ≥ 8 个 |
| 发现页→详情页点击率 | 在发现页点击商品卡片进入详情的比例 | ≥ 15% |
| 金刚入口点击率 | 四大金刚区域的总点击次数占发现页 PV 比例 | ≥ 20% |

---

## 3.3 用户旅程 (User Journey)

```
1. 用户点击底部 Tab "发现"
   → 页面分为两个区域：顶部金刚区 + 下方信息流

2. 顶部金刚区（固定不滚动或跟随首屏展示）
   → 展示 8 个圆形/方形图标入口：
     [淘宝特卖]  [品牌精选]  [天猫优选]  [京东自营]
     [聚划算]   [京东配送]  [神券大厅]  [特价专区]
   → 用户点击任一图标 → 进入对应的商品列表子页面

3. 金刚入口子页面
   → 展示对应 API 返回的商品列表（单列卡片）
   → 支持下拉刷新 + 上拉加载更多（分页）
   → 点击任意卡片 → 跳转详情页（PRD-02）

4. 下方信息流（朋友圈火爆瀑布流）
   → 双列交错卡片布局
   → 接入"朋友圈火爆商品 API"
   → 支持无限下拉加载（分页 page_size=20）
   → 点击任意卡片 → 跳转详情页（PRD-02）
```

## 3.4 功能需求与验收标准 (Requirements)

### REQ-0301 八大金刚导航入口

**描述：** 发现页顶部的 8 个功能快捷入口，承载各分类和场景的商品池。

**金刚入口配置：**

| 入口名称 | 说明 |
| :--- | :--- |
| 淘宝特卖 | 淘宝特价打折商品 |
| 品牌精选 | 精选淘宝、京东优质品牌商品 |
| 天猫优选 | 天猫官方优质商品 |
| 京东自营 | 京东自营优质商品 |
| 聚划算 | 淘宝限时团购、折扣商品 |
| 京东配送 | 支持京东物流快速配送商品 |
| 神券大厅 | 淘宝与京东的大额神券专区 |
| 特价专区 | 包含 9.9包邮、19.9包邮等低价专区子页面 |

**验收标准：**
- Given 发现页加载完成，When 页面渲染，Then 顶部展示 8 个两行四列排列的金刚图标，每个图标包含：图标图片 + 名称文字
- Given 用户点击"神券大厅"，When 触发导航，Then 跳转至商品列表子页面，页面标题为"神券大厅"
- Given 用户点击"特价专区"，When 触发导航，Then 跳转至商品列表子页面，提供 Tab 切换 `[9.9专区]` / `[19.9专区]`
- Given 金刚入口的图标和名称，When B 端后台修改配置，Then 下次小程序启动时自动更新（预留可配置能力）

### REQ-0302 朋友圈火爆瀑布流

**描述：** 发现页金刚区下方的主内容区域，以双列交错卡片形式展示社交验证属性极强的爆款商品。

**验收标准：**
- Given 发现页加载完成，When 金刚区下方渲染信息流，Then 展示双列交错卡片（左右两列，每列宽度各占屏幕 48%，中间 4% 间距）
- Given 每张商品卡片，When 渲染，Then 包含以下元素（从上到下）：
  - 平台来源 Tag（微型灰底标识"淘宝"或"京东"，样式与 PRD-02 REQ-0201 统一）
  - 商品主图（1:1 比例，圆角 8px）
  - 商品标题（最多 2 行，溢出省略）
  - 券后价（品牌主色 `#FF5500`，加粗）
  - 原价（灰色删除线，字号更小）
  - 券面额 Tag（如"券100元"，浅橙背景）
- Given 用户滚动至列表底部，When 触发加载区域（距底部 200px），Then 自动请求下一页数据（page + 1），追加到列表尾部
- Given 当前页面数据正在加载，When loading 状态，Then 底部展示加载指示器"正在加载更多..."
- Given 所有页面数据已加载完毕（API 返回空数组），When 到达末尾，Then 展示"已经到底啦~"提示

### REQ-0303 顶部搜索组件（内置淘券/京券切换）

**描述：** 发现页顶部固定展示一个搜索入口，并内嵌平台切换功能（淘券查询/京券查询）。

**优先级：** P0 · Phase 1.0 MVP

**验收标准：**
- Given 用户进入发现页，When 页面渲染，Then 顶部搜索框左侧或内部展示 [淘券 | 京券] 的局部切换控件。
- Given 搜索框点击，When 跳转独立搜索页，Then 继承当前选中的搜索平台进行检索。
- Given 搜索结果返回，When 渲染列表，Then 商品卡片展示对应的来源 Tag（"淘宝"或"京东"）。

### REQ-0304 居中数据流平台切换控件（淘喜/京喜）

**描述：** 在金刚区与瀑布流商品列表之间，放置一个居中的胶囊形平台切换控件，控制下方商品流数据源（淘喜商品 / 京喜商品）。

**优先级：** P0 · Phase 1.0 MVP

**验收标准：**
- Given 发现页加载完成，When 金刚区下方渲染，Then 展示居中的胶囊控件，包含 "淘喜商品" 和 "京喜商品"
- Given 用户点击 "京喜商品"，When 切换触发，Then 下方瀑布流内容无缝切换为京东平台相关的数据流
- Given 用户滚动瀑布流，When 数据加载，Then 始终展示选定平台的数据，且切换动作不会影响页面全局顶部颜色或搜索组件的平台状态。

### REQ-0305 京东专区商品池

**描述：** 在分类 Tab 中提供京东平台的细分商品池入口，覆盖京东主流购物场景。

**优先级：** P0 · Phase 1.0 MVP

**京东四大池：**

| 池名称 | 数据源 | 筛选条件 |
| :--- | :--- | :--- |
| 京东自营 | ZTK #7 京东搜索 | `owner=g`（自营标识） |
| 京东好店 | ZTK #7 京东搜索 | `isHot=1`（好店标识） |
| 京东拼购 | ZTK #7 京东搜索 | `pingouPrice > 0`（参与拼购） |
| 京东配送 | ZTK #7 京东搜索 | `deliveryType=1`（京东物流） |

**验收标准：**
- Given 用户点击"京东自营"Tab，When 数据加载，Then 瀑布流仅展示京东自营商品，每张卡片展示"京东"灰底 Tag
- Given 京东商品卡片，When 渲染价格区域，Then 需根据京东特有的优惠结构展示：
  - 若有优惠券：展示券后价 + 券面额 Tag
  - 若仅有满减/PLUS 立减：展示预估到手价 + "满减"/"PLUS" Tag
  - 若无任何优惠：仅展示售价，不展示省钱 Tag
- Given 京东商品无 `couponPrice` 但有 `priceInfo` 中的划线价，When 渲染，Then 使用划线价作为原价展示对比

### REQ-0306 双端大牌频道（P1 · Phase 1.5）

**描述：** 在分类 Tab 中新增"大牌精选"频道，展示淘宝与京东的品牌正品商品瀑布流。

**优先级：** P1 · Phase 1.5

**验收标准：**
- Given 用户点击"大牌精选"Tab，When 数据加载，Then 展示经折淘客品牌库筛选的品牌商品
- Given 品牌商品卡片，When 渲染，Then 额外展示品牌名称标签（如"Nike""小米"）

### REQ-0307 商品卡片平台来源标识（全局 Card UI 规范）

**描述：** 发现页所有商品卡片统一展示平台来源微型 Tag，使用户一眼识别商品来自淘宝还是京东。此规范与 PRD-02 REQ-0201 和 PRD-05 REQ-0501 保持一致。

**优先级：** P0 · Phase 1.0 MVP

**验收标准：**
- Given 任何商品卡片渲染，When 商品数据包含 `platform` 字段，Then 在商品标题上方展示微型 Tag
- Given Tag 样式，When 渲染，Then 统一使用灰底样式（背景 `#F5F5F5`，文字 `#666`，圆角 4px，字号 10px），**不使用平台品牌色**
- Given 淘宝商品，When Tag 渲染，Then 展示文字"淘宝"
- Given 京东商品，When Tag 渲染，Then 展示文字"京东"

## 3.5 边界与异常 (Edge Cases)

| 场景 | 系统行为 |
| :--- | :--- |
| **信息流首次加载失败** | 展示 Empty State 插画 + "加载失败，点击重试" 按钮 |
| **金刚入口子页面无数据** | 展示"暂无相关商品，稍后再来看看" |
| **京东商品池为空（接口无数据）** | 对应 Tab 展示空状态，不隐藏 Tab 本身 |
| **下拉刷新** | 支持下拉刷新整个页面，金刚区不变，信息流重新从第 1 页加载 |
| **快速切换 Tab 再切回** | 保留之前的滚动位置和已加载数据，不重新请求 |
| **Tab 切换时上一个请求尚未返回** | 取消上一个请求（AbortController），避免数据错乱 |
| **搜索框点击** | 跳转独立搜索页，不在发现页内展开搜索 |

## 3.6 非功能性需求 (Non-Functional Requirements)

| 类别 | 要求 |
| :--- | :--- |
| **性能** | 首屏（金刚区 + 第一页瀑布流）加载 ≤ 2 秒 |
| **Tab 切换** | 切换 Tab 后新数据首屏渲染 ≤ 1.5 秒 |
| **图片优化** | 商品图使用缩略图 URL（宽度 300px），非原图，减少流量消耗 |
| **分页** | 每页 20 条，最多加载 50 页（1000 条）作为上限，防止内存溢出 |
| **Tab 缓存** | 已加载的 Tab 数据在 Session 内缓存，切回时不重新请求 |
| **埋点** | 金刚区各入口点击、Tab 切换、瀑布流曝光、卡片点击、搜索框点击、分页加载次数 |
