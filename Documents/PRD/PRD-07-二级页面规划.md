# 小栗鼠 3.0 二级页面设计与功能规划

基于“纯导购省钱工具”的定位（完全免费、无需充值、无需会员），以及“我的”页面最新的菜单结构，我们移除了原有的“我的订单”、“我的收藏”等重度电商功能。

以下是所有需要设计的**二级页面及其核心功能点**的最终梳理。请审阅，确认无误后我们将逐一开始 UI 设计与代码落地。

---

## 1. 核心链路页 (Core Flow)

### 1.1 商品详情页 (`pages/detail/detail`)
> 用户决策购买的核心页面
- **视觉层**：商品主图/视频轮播、商品基本信息（大字号券后价、原价、高亮大额优惠券标签）、长图文详情展示。
- **操作层**：
  - “领券购买”主按钮（自动复制淘口令并提示打开淘宝/京东）。
  - “复制口令/链接”次级按钮。
  - 悬浮返回首页/客服按钮。
- **状态提示**：商品下架、优惠券过期等失效状态兜底展示。

### 1.2 搜索结果页 (`pages/search-result/search-result`)
> 用户主动找券的承接页
- **顶栏区**：吸顶搜索框（带清空按钮，支持修改关键词）。
- **筛选排序**：综合、销量优先、价格排序（高到低/低到高）。
- **结果展示**：瀑布流或单列大图商品卡片（包含商品图、平台标签、券面额、券后价、预估省钱金额）。
- **空状态**：无结果时的插画提示，并附带“为您推荐”的热门好物。

### 1.3 分类列表页 (`pages/categorylist/categorylist`)
> 提供类目级的找券体验
- **结构**：侧边栏大分类（女装、美妆、食品等） + 右侧细分小分类。
- **列表**：点击分类后，展示该类目下的商品无限滚动列表。

## 2. “我的”模块专属二级页 (Mine Module)

### 2.1 我的找券足迹 (`pages/history/history`)
> 帮助用户找回看过的心动商品
- **展示逻辑**：按时间维度（如：今天、昨天、更早）时间轴分组。
- **卡片信息**：缩略图、商品标题、当时的券后价。
- **状态标识**：若该商品优惠券已抢光或下架，卡片需置灰并打上失效标签。
- **管理功能**：支持滑动删除单条记录，或一键清空所有足迹。

### 2.2 使用教程 (`pages/guide/guide`)
> 降低新手使用门槛
- **图文并茂**：分步骤卡片流，演示“淘宝复制链接” -> “打开小栗鼠自动查券” -> “领券跳转购买”的完整闭环。
- **视频演示（可选）**：顶部支持播放 15-30s 的录屏教学视频。
- **转化引导**：底部悬浮“去查券试试”大按钮，点击返回首页唤起剪贴板识别。

### 2.3 联系我们 (半屏弹窗组件或 `pages/contact/contact`)
> 私域流量沉淀与售后服务
- **展示方式**：点击后从底部弹出的半屏组件（基于 PRD-06）。
- **包含选项**：
  - **加入社群**：展示官方群二维码，支持“长按识别”或“保存二维码”。
  - **专属客服**：展示个人微信客服号，支持“一键复制微信号”。
  - **客服电话**：点击直接唤起手机拨号盘。

### 2.4 常见问题 (`pages/faq/faq`)
> 降低客服压力
- **手风琴列表**：问题折叠面板（点击展开对应解答）。
- **问题分类**：如【查券类】、【购买类】、【售后类】。
- **底部求助**：页面最下方保留“未解决？联系专属客服”的引导入口。
