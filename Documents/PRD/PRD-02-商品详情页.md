## 2.1 问题陈述 (Problem)

### 谁有这个问题？
已搜索到商品优惠信息的用户，需要一个清晰、直观、可信的"算账页面"来做出最终购买决策，并需要一个低成本的裂变出口将优惠信息分享给他人。

### 有多痛？
- 用户看到"有券"但无法直观理解"到底能省多少钱"，缺乏原价与券后价的强对比刺激。
- 用户想分享给朋友，但直接转发淘口令消息太"low"，缺乏一张体面的、有视觉冲击力的推广海报。

### 不做会怎样？
用户查到券后不敢下单（转化率低），也无法自发裂变（增长停滞）。

---

## 2.2 成功指标 (Success Criteria)

| 指标 | 定义 | 目标值 |
| :--- | :--- | :---: |
| 详情页→口令复制率 | 进入详情页后成功复制淘口令/京东链接的比例 | ≥ 50% |
| 海报生成率 | 进入详情页后点击"生成海报"的比例 | ≥ 8% |
| 海报保存率 | 生成海报后成功保存到相册的比例 | ≥ 90% |
| 页面加载耗时 | 从跳转到详情页完整渲染的时间 | ≤ 2 秒 |

---

## 2.3 用户旅程 (User Journey)

```
1. 用户从查券/发现/榜单/晒单任意页面，点击商品卡片
   → 携带商品 ID (tao_id) 跳转详情页

2. 详情页加载
   → 调用云函数 cf-product-detail（传入 tao_id）
   → 展示骨架屏（商品图占位 + 价格占位 + 按钮占位）

3. 数据返回，页面渲染完成
   → 顶部：商品主图（支持左右滑动多图浏览）
   → 中部：算账对比区（原价划线 + 券面额 + 券后价大字）
   → 底部固定栏：[领券购买] 按钮（品牌主色）+ [生成海报] 按钮

4a. 用户点击 [领券购买]
   → 调用云函数 cf-convert-link（高佣转链）
   → 淘宝：生成淘口令 → 自动复制到剪贴板 → 弹窗提示"口令已复制，打开淘宝即可领券"
   → 京东：生成京东短链 → 自动复制到剪贴板 → 弹窗提示"链接已复制，打开京东即可购买"

4b. 用户点击 [生成海报]
   → 弹出全屏海报预览浮层
   → Canvas 合成海报（商品图 + 标题 + 价格对比 + 小程序码）
   → 用户点击 [保存到相册] → 调用 wx.saveImageToPhotosAlbum()
   → 保存成功 → Toast "已保存到相册，快去分享吧"
```

## 2.4 功能需求与验收标准 (Requirements)

### REQ-0201 算账比价展示区

**描述：** 用极强的视觉对比展示原价与券后价，让用户一眼看出"能省多少钱"。

**验收标准：**
- Given 商品数据返回成功，When 详情页渲染，Then 展示以下信息层级：
  - 第零行：平台来源标签（微型 Tag），淘宝商品展示"淘宝"Tag、京东商品展示"京东"Tag。Tag 使用统一灰底样式（背景 `#F5F5F5`，文字 `#666`），**不使用平台品牌色**，保持栗橙主色调不被干扰
  - 第一行：券后价，使用品牌主色 `#FF5500`，字号 ≥ 28px，加粗
  - 第二行：原价，使用辅色 `#999999`，字号 14px，带删除线
  - 第三行：优惠券面额标签（如"领100元券"），使用浅橙色背景 + 主色文字的 Tag 样式
  - 第四行：预估省钱金额（如"预计可省 ¥100"），使用警示红 `#FF2D2D`
- Given 商品无优惠券（券面额为 0），When 详情页渲染，Then 隐藏券面额标签行和省钱金额行，仅展示商品原价
- Given 商品标题过长（>2 行），When 渲染标题，Then 截断至 2 行末尾显示"..."

### REQ-0202 高佣转链 / 领券 CTA

**描述：** 详情页底部固定栏的核心行动按钮，完成从"看"到"买"的临门一脚。

**验收标准：**
- Given 用户点击 [领券购买]，When 按钮触发，Then 立即进入 loading 态（按钮文案变为"正在获取优惠..."），禁止重复点击
- Given 云函数 cf-convert-link 返回淘口令，When 返回成功，Then 自动调用 `wx.setClipboardData()` 写入剪贴板，弹出确认弹窗
- Given 确认弹窗展示，When 弹窗内容，Then 包含：
  - 文案："淘口令已复制到剪贴板"
  - 副文案："打开淘宝 APP 即可领券购买"
  - 按钮：[我知道了]（关闭弹窗）
- Given 云函数返回京东短链，When 返回成功，Then 同上流程，文案替换为"京东链接已复制"
- Given 转链请求失败，When 超时或返回错误，Then 按钮恢复可点击状态，Toast 提示"获取优惠链接失败，请稍后重试"
- Given 商品无优惠券，When 用户点击按钮，Then 按钮文案改为"直接购买"，转链仍走高佣逻辑（赚佣金但用户无券可领）

### REQ-0203 Canvas 海报生成器（P0 裂变核武器）

**描述：** 利用微信小程序 Canvas API，在前端本地合成一张包含产品信息和小程序入口码的推广海报图片。

**海报布局规格：**
```
┌─────────────────────────────┐
│         商品主图              │  ← 商品第一张主图，宽度占满，高度自适应
│        (占海报 60%)           │
├─────────────────────────────┤
│  商品标题（最多2行）          │  ← 字号 16px，颜色 #1A1A1A
│                              │
│  ¥ 89.9（券后价·大字）       │  ← 字号 28px，颜色 #FF5500，加粗
│  ¥ 189.9（原价·删除线）      │  ← 字号 14px，颜色 #999999
│  领100元隐藏券               │  ← Tag 样式
│                              │
│  ┌──────┐                   │
│  │小程序 │  长按识别小程序码   │  ← 小程序码 120x120px
│  │  码   │  查看商品详情       │     右侧引导文案
│  └──────┘                   │
│                              │
│  ── 小栗鼠 · 帮你省钱 ──     │  ← 底部品牌水印，字号 12px
└─────────────────────────────┘
```

**验收标准：**
- Given 用户点击 [生成海报]，When 触发，Then 弹出全屏半透明遮罩 + 海报预览浮层，浮层底部有 [保存到相册] 按钮
- Given 海报合成过程中，When Canvas 绘制耗时，Then 展示 loading 动画"海报生成中..."
- Given Canvas 合成完成，When 海报预览就绪，Then 展示完整海报图片预览
- Given 用户点击 [保存到相册]，When 调用 `wx.saveImageToPhotosAlbum()`，Then 成功后 Toast "已保存到相册"
- Given 用户未授权相册权限，When `saveImageToPhotosAlbum` 失败（权限拒绝），Then 弹窗引导用户前往设置页开启权限
- Given 海报中的小程序码，When 生成参数，Then 必须携带当前商品 ID 作为 scene 参数，确保扫码后直达该商品详情页
- Given 海报按钮设计，When 任何时候，Then **不得使用红点提醒或动态抖动效果**（微信合规 5.1.2）
- Given 海报底部品牌水印，When 任何时候，Then **不得出现"分享到朋友圈领XX"等利益诱导文案**（微信合规 5.1.3）

## 2.5 边界与异常 (Edge Cases)

| 场景 | 系统行为 |
| :--- | :--- |
| **商品已下架** | 详情页展示 Empty State："该商品已下架"，提供 [返回首页] 按钮 |
| **优惠券已过期/已抢光** | 隐藏券面额 Tag，券后价区域改为显示原价，CTA 按钮改为"直接购买" |
| **商品图片加载失败** | 展示灰色占位图 + 品牌 Logo 水印 |
| **小程序码生成失败** | 海报中小程序码区域替换为文字"微信搜索'小栗鼠'查看详情" |
| **Canvas 绘制失败（低端机）** | 捕获异常，Toast "海报生成失败，请重试"，按钮恢复可点击 |
| **商品无主图** | 使用默认占位图 |

## 2.6 非功能性需求 (Non-Functional Requirements)

| 类别 | 要求 |
| :--- | :--- |
| **性能** | 详情页数据加载 ≤ 2 秒；Canvas 海报合成 ≤ 3 秒（中端机型基准） |
| **图片规格** | 海报输出分辨率：宽 750px（2倍屏适配），格式 PNG |
| **缓存** | 同一商品 ID 的详情数据在 Session 内缓存，避免重复请求 |
| **埋点** | 必须埋点：页面 PV、领券按钮点击、海报生成点击、海报保存成功/失败 |
