
# 《极省惠选/老温铺子》小程序 MVP 前端功能说明书 (V1.1.0)

## 一、 产品共识与底线原则

- **核心定位**：微信生态内，极简、纯自用、完全合规的 CPS 优惠导购小程序。
- **绝对红线**：全端代码及 UI 彻底封杀“返现、返利、佣金”等敏感词；坚决不开发提现与绑定银行卡功能。
- **技术杠杆**：强制采用微信官方原生 WeUI 组件库，保障小程序极速秒开。


----
## 二、 最短用户操作路径 (核心漏斗)

前端设计遵循“零摩擦”原则，核心转化路径严格压缩在 3 步以内：
1. **触发 (自动嗅探)**：用户复制电商商品链接，打开小程序，系统自动识别并弹窗。
2. **决策 (积分替换现金)**：用户查看弹窗中的“券后价”与“预估可得积分”。
3. **闭环 (一键跳转)**：点击“去购买”，直接拉起淘宝/京东/拼多多官方 APP 完成交易。


----
## 三、 前端核心 API 交互节点

前端小程序仅作为“展示层”与“跳转中枢”，禁止直接连通第三方聚合平台。必须通过以下 3 个云开发 (Serverless) 节点进行交互：
- **节点 1：`parse_and_convert` (查券转链)**
	- 输入：剪贴板文本 (Text)、用户唯一标识 (OpenID)。
	- 输出：商品主图、原价、券后价、预估积分、带有平台 PID 和 `source=search` 归因参数的跳转链接。
- **节点 2：`get_ttl_feed` (获取种草流)**
	- 输入：分类标签 (Tab ID)。
	- 输出：云端数据库中 48 小时内有效的高佣商品列表。
- **节点 3：`get_user_assets` (获取资产与订单)**
	- 输入：用户唯一标识 (OpenID)。
	- 输出：当前可用积分余额、近 30 天的订单对账状态列表。

## 五、 业务流转伪代码 (前端核心防穿透逻辑)

JavaScript
```
// 全局前置：强制规避合规词汇的资金格式化函数
function formatMoneyToPoints(commission_cash) {
    // 强制按 1:1 汇率换算
    const points = commission_cash * 1; 
    return `预估可得 ${points} 积分`; // 坚决不输出“返现”
}

// 核心查询逻辑
async function handleUserSearch(clipboardData, openId) {
    if (!isEcommerceLink(clipboardData)) return; // 零打扰原则
    
    try {
        const result = await wx.cloud.callFunction({
            name: 'parse_and_convert',
            data: { query: clipboardData, user: openId }
        });
        
        // 渲染 UI：安全展示
        renderUI({
            image: result.cover_image,
            discount: `立减 ${result.coupon_amount} 元`,
            reward: formatMoneyToPoints(result.commission_cash), // 调用安全函数
            jumpUrl: result.alipay_or_jd_scheme_url // 携带 source=search 的转链
        });
    } catch (error) {
        showToast('该商品暂无专属优惠'); // 异常不报错，用话术兜底
    }
}
```
