# 《小栗鼠》后台管理系统功能说明书 (V1.2.0)

## 一、 后端设计总纲

- **核心定位**：极简财务收银台与风控驾驶舱，主打“高净值、低信噪比”的数据展现。
- **视觉风格**：采用 Swiss Clean Light 极简主义设计，白橙色调对齐小程序品牌色 (#FF6B35)。
- **实时监控**：全局顶部集成“生产环境 (Production) 🟢”状态指示，确保操作环境透明。
- **安防底线**：超级管理员单点登录，底部常驻身份审计信息，不支持由于多级权限导致的系统臃肿。

## 三、 通用交互规范 (V1.2.0 标准)

为了确保后台操作的高效性与一致性，所有列表类页面均遵循以下通用交互逻辑：

1. **全局搜索 (Search)**：
   - 每个列表页顶部均配备搜索栏。
   - 支持关键字联想或模糊匹配（如：订单号后 6 位、OpenID 前缀等）。
   - 搜索响应时间优化，确保数据即搜即得。

2. **多维排序 (Sorting)**：
   - 所有列表字段支持正序/倒序切换。
   - **默认规则**：财务流水与任务日志默认为“业务发生时间”倒序（最新数据在最上方）。
   - 点击表头字段可一键切换排序维度，提升异常数据追踪效率。

3. **智能分页与容量切换 (Pagination)**：
   - 采用标准分页器组件，支持一键翻页及跳转至指定页。
   - **每页显示量快速切换**：默认每页显示 10 条数据，支持下拉切换至 20、50 或 100 条/页，系统将持久化用户最后一次的选择。

4. **数据统计反馈**：
   - 列表顶部实时显示“共 XXX 条记录”字样，反馈当前统计总量。

- **零边际成本**：商品上架与物流发货 100% 托管于官方生态，本系统仅负责财务合规与利差数据。
