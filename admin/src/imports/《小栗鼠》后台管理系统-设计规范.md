# 《小栗鼠》后台管理系统 - UI/UX 设计规范 (V1.1)

## 一、 设计理念与技术选型

1. **品牌同频**：后台系统与小程序端共享同一套色彩与字体 DNA，确保创始人与运营人员在切换 C端/B端 时，拥有统一的“算账本位”视觉心智。
2. **极简拼装**：绝对禁止手写自定义 CSS 样式。推荐使用基于 **Ant Design (React)** 或 **Element Plus (Vue 3)** 的后台模板，通过**全局修改 Theme Token（主题变量）**一键覆盖默认色。
3. **数据降噪**：摒弃多余的装饰性色彩，大面积留白，让核心的财务数据（佣金、积分）和状态标签成为视觉焦点。

## 二、 页面布局规范 (Layout)

基于主流显示器分辨率（以 `1920 x 1080` 为基准设计，向下兼容适配，向上自动适应 ）：

1. **全局架构**：采用经典的**左右/上下混合布局**。
   - **侧边导航栏 (Sider)**：深色背景为主（暗黑模式下使用 `#111111`，浅色模式下可保持纯白或深色），选中项的高亮色严格使用主色浅 `#FFF0E8` + 左侧主色边框 `#FF6B35`。
   - **顶部顶栏 (Header)**：固定高度 `56px`。右侧仅保留：管理员头像、退出登录按钮。
   - **内容区域 (Content)**：页面底色统一为 `#F5F5F5`，各业务模块以纯白卡片 `#FFFFFF` 承载，卡片内边距统一为 `24px`。
2. **栅格系统**：采用 **24 栅格系统**，区块之间横向与纵向的安全间距（Gutter）统一使用 `16px` 或 `24px`。

## 三、 核心色彩体系 (Color Palette - 严禁偏离)

以下色彩体系已完全与 C 端小程序对齐。在配置 Ant Design 或 Element Plus 的主题包时，请直接将以下色值写入全局变量。

### 3.1 品牌色 (Brand)

用于全局的视觉引导、核心交互和数据强调。

## 四、 核心组件设计约束 (Components)

基于上述色彩体系，我们在后台搭建时需遵循以下标准：

### 1. 按钮 (Buttons)

- **主按钮 (Primary)**：背景色 `#FF6B35`，文字 `#FFFFFF`，悬停色 `#E55A2B`。用于“查询”、“导出财务报表”、“保存配置”。
- **次按钮 (Default)**：背景色 `#FFFFFF`，边框 `#E5E5E5`，文字 `#353535`。用于“重置”、“取消”。
- **危险按钮 (Danger)**：文字或背景使用 `#FA5151`。用于不可逆的破坏性操作（MVP阶段极少用到）。

### 2. 状态标签 (Tags) - _对账核心视觉_

订单列表中，状态列必须使用带有透明度的 Tag 进行强视觉区分，严禁仅用纯文本：

- **待结算**：`<Tag color="#FFA940" style="background: rgba(255,169,64,0.1); color: #FFA940; border: none;">待结算</Tag>`
- **已入账**：`<Tag color="#07C160" style="background: rgba(7,193,96,0.1); color: #07C160; border: none;">已入账</Tag>`
- **已失效**：`<Tag color="#888888" style="background: rgba(136,136,136,0.1); color: #888888; border: none;">已失效</Tag>`

### 3. 表格对齐与排版 (Data Tables)

- **对齐原则**：金额、订单数、积分等**数值类一律右对齐**（方便小数点对齐与财务审阅）；文本、状态类一律**左对齐**。
- **空数据占位**：当某项数据为空时，必须使用短横线 `-`（颜色 `#B2B2B2`）占位，严禁留白。
